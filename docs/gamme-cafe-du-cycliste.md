# Café du Cycliste : aperçu de la gamme (novembre 2026)

**Source** : le catalogue public de cafeducycliste.com, extrait le 20/11/2026. Il compte 792 produits, dont 494 vêtements et gants rangés dans [`data/catalogue.csv`](../data/catalogue.csv). Les gammes viennent des pages « collection » du site (Race, Audax, Classic, Outlands, Active, Explore).
Les **prix** sont les prix catalogue en € hors soldes. Les **températures** sont **mes estimations** : je les ai déduites de la description de chaque produit (grammage, tissu, usage annoncé). Le site affiche une échelle graphique −10 °C / +30 °C sur chaque fiche, mais il ne publie pas de chiffres exploitables. Vérifiez sur la fiche produit avant de vous y fier.
